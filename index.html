Struktur Data

Cara menyimpan dan mengatur data agar mudah dicari dan diubah, seperti cara menata isi lemari.

Tree

Struktur hierarki tanpa siklus. Ada satu Root di atas. Parent punya Child; node dengan parent yang sama disebut Sibling; node tanpa child disebut Leaf. Root berada di level 0.

      A   (Root, level 0)
     / \
    B   C (level 1)
   / \
  D   E   (Leaf, level 2)

Tree dengan n node selalu punya n − 1 edge.

Graph

Kumpulan Vertex (node) yang dihubungkan Edge. Path adalah jalur antar vertex, Degree adalah jumlah edge pada sebuah vertex. Graph boleh punya siklus dan bisa berarah (directed) atau tidak (undirected).

A ━━ B
┃    ┃
C ━━ D

Tree vs Graph

Tree Graph
Bentuk Hierarki Jaringan bebas
Root Ada satu Tidak ada
Siklus Tidak boleh Boleh
Edge n − 1 Bebas

Tree: folder komputer, struktur organisasi. Graph: peta jalan, media sosial, jaringan komputer.

Cara Bermain

  1. Pilih 2–4 pemain. Tiap pemain punya 1 pion dan mulai dari petak berwarna miliknya.
  2. Bergiliran lempar dadu, pion berjalan searah jarum jam. Tidak ada mundur.
  3. Berhenti di petak bergambar: jawab soal sebelum waktu habis.
  4. Setelah satu putaran, pion masuk lorong warna menuju pusat papan.
  5. Pemain pertama yang sampai pusat menang (+200 poin). Jika waktu 20 menit habis, skor tertinggi menang.

Tentang

Game edukasi untuk memahami Tree dan Graph lewat permainan Ludo. Alurnya: memahami (materi), menerapkan (soal di papan), merefleksikan (refleksi akhir). Cocok untuk sesi kelas 15–20 menit.

Game ini mendukung beragam gaya belajar: visual (diagram dan warna), auditori (narasi suara di Materi dan Lab), dan kinestetik (game serta Lab Praktik). Siswa tidak terkunci pada satu gaya; gunakan ketiganya bergantian: lihat diagram, dengarkan penjelasan, lalu coba sendiri.
